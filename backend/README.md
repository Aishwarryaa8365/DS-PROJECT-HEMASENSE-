# Backend

Flask application for HemaSense.

## Entry point

Start from the **project root**:

```bash
python run.py
```

Or directly:

```bash
python backend/app.py
```

## Key files

| File            | Purpose                                      |
|-----------------|----------------------------------------------|
| `app.py`        | Flask routes, auth, prediction logic         |
| `config.py`     | Centralised path and environment config      |
| `requirements.txt` | Python dependencies                       |

## Install dependencies

```bash
pip install -r backend/requirements.txt
```
